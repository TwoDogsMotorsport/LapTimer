# Security Policy

Everyone needs to take security seriously, and while this code is not intended to communicate with any other device there is no way to predict what vulnerabilities might occur in future.

## Supported Versions

Reasonable effort will be made to address legitimate issues or improvements for the versions listed in the next table:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| 0.0.x   | :x:                |

## Reporting a Vulnerability

To report a vulnerability or improvement, please raise an issue in this repository.

Thank you!
